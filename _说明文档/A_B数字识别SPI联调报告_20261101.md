## 当前实现

- B：原检测器 `digit_done` 缓存 x/y/w/h/class，`frame_done` 后构造不可变包；SPI 读取期间不换发布 bank。
- 每组最多 16 个结果；0 个结果仍发布空帧，使旧框可以清除。溢出有标志，不用固定十个数字。
- 包含模型自检的权重 CRC。当前模型没有导出置信度分数，本协议不会把 CRC 或类别伪作置信度。
- A：校验命令响应、版本、CRC16、数量、类别、坐标和框尺寸；错包不更新结果。
- 相同结果序号的重复轮询不会重置新鲜度计时；超过 3 秒没有新结果则清除显示资格。
- A MCU：`显示模式 → 数字识别`，独立开关，默认关闭，按键和触摸都可切换。该开关控制叠框显示，B 的 CNN 继续运行。
- A：320×180 坐标按横纵各 6 倍映射到现有 1920×1080 显示；绿色框线和类别字形。
- 叠框采用双 bank 的 320×180 1-bit 位图，6 倍展开；边框约 6 屏幕像素，数字约 30×42 屏幕像素。
- 位图逐项构建，整组只在 VSYNC 换 bank；新增视频延迟两拍，RGB/DE/HS/VS 一起对齐；空帧也更新。
- 最新识别结果并不与 A 板当前显示的摄像头帧严格绑定，快速运动时可能有识别/轮询/显示缓存延迟。
- B 的默认 UART 改为现有文本识别通路（D/FRAME_DONE/STAT），不再默认发送 VOFA 二进制图片；诊断图像模块源码仍保留。

## SPI 包（160 字节）

MOSI 第一个字节为 `A5`，剩余填零，同时采集 MISO。命令错误时 B 不返回完整有效包。

| 偏移 | 字段 |
|---|---|
| 0..1 | ASCII DG（44 47） |
| 2 | 版本 01 |
| 3 | bit0 valid，bit1 overflow；其他位 0 |
| 4..5 | 结果序号，16-bit 大端；不是传感器物理帧号 |
| 6 | 目标数 0..16 |
| 7 | 保留 0 |
| 8..151 | 16 槽 × 9 字节：x/y/w/h 各 16-bit 大端 + class 8-bit；未用槽为 0 |
| 152..155 | 权重 CRC32 大端 |
| 156..157 | CRC16-CCITT-FALSE：初值 FFFF，多项式 1021，不反射；覆盖 0..155 |
| 158..159 | CR LF（0D 0A） |

接受条件：class≤9，w/h>0，x+w≤320，y+h≤180；溢出标志可以为 1，但包内有效槽仍必须满足检查。

## A 板 APB 与串口

基址 `0x70004000`，和既有菜单、直方图、录像页面独立；状态跨域使用 held-bundle 请求/应答快照。

| 偏移 | 定义 |
|---|---|
| 00 | 53504447，SPDG 标识 |
| 04 | bit0 叠框使能，可写；复位 0 |
| 08 | [31:16] 最新结果序号；bit7 overflow；[6:2] 数量；bit0 新鲜结果有效 |
| 0C | 模型权重 CRC32 |
| 10 | 通过协议/CRC/语义检查的包数（包含相同序号的轮询） |
| 14 | 无效包数（启动时 B 未产生结果也可能增长） |
| 18 | 000101F4：版本 1，标称 500 kHz |

A 板现有视频诊断每两秒附带 `CNN: 4004=...` 至 `CNN: 4014=...`，用于区分菜单关闭、链路错误和有包但没有新识别结果。
实际坐标/类别文本仍从 B 板原串口读取。没有改 B 板 MCU。
