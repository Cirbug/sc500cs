MCU picture controls (PIC1), 2026-10-13

2026-10-22: GAM1 bitstreams replace the gamma OFF/ON switch with an 8-step
slider (0=OFF, 1..8 = 0.30..0.65; Sobel keeps 0.45).  The XIP firmware carries
the slider; the TCM image keeps the old OFF/ON switch because it has no room.
See tests/GAMMA_SLIDER.txt.

2026-10-26: adds lens-shading correction (LSC) and cross-reconfiguration state
retention from the "picture repair" branch, merged with the GAM1 slider above.
LSC strength is menu item IMAGE -> 色度 (APB 0xec/0xf0/0xf8, 8-bit, 0..255) and runs
in the display domain after video_out, where gamma is off.  FPGA reset, the
picture mailbox INIT and firmware PICTURE_DEFAULT are now all 0x108c; keep them
in step or the picture jumps on every bit load.  See lens_shading_correction.v.

Main menu: select PICTURE (former inert PAN row), press OK or tap the row.
Picture page:
  Physical keys: UP/DOWN select; OK edit; UP increases, DOWN decreases.
  BACK exits editing, then BACK returns to the main menu.
  Touch label/left side to decrease; value/right side to increase.
  Touch header/BACK to return. DEFAULT restores picture parameters only.
  Exposure, sensor gain, servos, logo and display mode are not reset by DEFAULT.
  Physical keys and touch edit the same MenuState in both firmware targets.

BLACK: 0..63, saturating subtraction in 8-bit RGB, MCU default 12.
GAMMA: GAM1 slider 0=OFF, 1..8 = 0.30..0.65 on the XIP firmware; the TCM
     image keeps the old OFF/ON switch. Sobel edge display (MODE 1/2, EFFECT 5)
     forces the historical 0.45 curve; leaving it restores the user's setting.
     The OSD shows the effective value, so Gamma remains 0.45 during Sobel.
BRIGHT: 1.0/1.125/1.25/1.5, default 1.125; displayed as 1.12.
SAT: 1.0/1.25/1.5/1.75/2.0, default 1.0.
AWB: AUTO (unsmoothed), SMTH (IIR + clamp), GRAY (near-gray 32 + SMTH),
     OFF (unity R/B gain). Default SMTH. Black subtraction is independent.
DENOISE: OFF/LOW/MID/HIGH, default OFF. Edge-limited spatial filtering of
     actual display pixels after linear scaling and before gamma; not temporal
     frame averaging. First line bypasses vertical filtering; strong edges
     bypass filtering. The existing recognition-side denoiser is retained.

Register map, base 0x70000000:
  0x08 bit3: picture page (bits0..2 remain menu/edit/info)
  0x70 bits5:0 black, bit6 gamma, bits8:7 brightness 0..3,
       bits11:9 saturation 0..4, bits13:12 AWB 0..3,
       bits15:14 denoise 0..3. FPGA reset and firmware DEFAULT are both 0x108c;
       MCU startup writes it explicitly (BLACK=12, gamma OFF, brightness 1.125x).
       Requires both low byte strobes; invalid saturation clamps to 4.
  0x6c GAM1: write low 4 bits = gamma level (0=OFF, 1..8=0.30..0.65);
       read 0x47414D30 | level.  GAM1 and PIC1 share the 20-bit frame-boundary
       mailbox.  XIP only; TCM keeps the old OFF/ON PIC1 bit.
  0x74 read-only 0x50494331 (PIC1).
  0xec LSC: write low 8 bits = lens-shading strength (0 = bypass, 128 = table
       as-is, 112 = the old 5-bit "14" working point, 255 = about 199%).
       Read back as {24 zero bits, value}.
  0xf0 read-only 0x4c534331 (LSC1 capability: LSC present).
  0xf8 read-only 0x434f4c31 (COL1 capability: 8-bit LSC strength + three-colour
       recognition / target tracking -- they always ship together on this line).
       An older bit without COL1 only has LSC1 and takes 5-bit values (16 = table
       as-is); firmware then scales by 8:1 (v<<3), so the same menu step (old 14)
       lands on the same working point (new 112).
  0x58 IMAGE_CTRL: mode values 0..7 are all accepted now -- 0 = colour recognition,
       2 = normal, 3 = shape, 4 = motion, 5/6/7 = track red/blue/green.  (Mode 1 is
       reserved: auto-colour tracking is not implemented.)
MCU checks PIC1 before exposing the submenu or writing the new register.
The requested word crosses each clock domain through an acknowledged mailbox;
the ISP applies it only on frame start. OSD values may lag the edit briefly.
Settings are volatile across power cycles: boot/default restores the profile.
The TCM firmware additionally survives an FPGA reconfiguration (TD bit load)
via the .wifi_noinit block in main.c, so re-loading a bit no longer changes the
picture; that spans MCU reset only, not power loss. No Flash settings
persistence or RTC calibration is added by this change.
The BLACK=12/gamma-OFF/Sobel-override update requires only new MCU firmware
when the PIC1 FPGA bitstream is already installed. No new FPGA build needed.
