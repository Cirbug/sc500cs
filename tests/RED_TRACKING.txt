控制策略
  进入挡位 4 后自动跟随，默认启动仍是普通画面。
  FPGA 已有滞回死区：横向停止/启动为 32/48 像素，纵向为 24/36 像素。
  偏差等级 1/2/3 对应每次 1/2/4 us 增量；两次调整至少相隔 80 ms。
  每帧结果最多执行一次，更新过快的结果被消费但不会累积补走。
  使用现有 500..2500 us 限位；丢失目标时保持最后的 PWM 位置，不关闭 PWM。
  手动触摸拖动优先；进入模式、重新捕获、松开拖动后先等待 200 ms 和新结果。
  任一失效结果重置等待基准，恢复锁定后至少距最后失效结果 200 ms 才追加运动。
  250 ms 没有新结果时标为 STALE；恢复后丢弃滞留结果，重新等待再行动。
  此超时针对识别结果邮箱；摄像头冻结而 HDMI 重复旧画面的检测不在本次范围内。
  退出挡位 4、旧 FPGA 没有 TRK1、运行时禁用跟随，均不再追加自动舵机命令。
  用户已确认首版两轴方向反转；修正后的方向、响应速度、机械行程和负载需实机复测。

APB 接口（基地址 0x70000000）
  0x50 / 0x54：原有 PAN / TILT 脉宽，单位 us。
  0x58：原有 IMAGE_CTRL，bits[2:0]=5 为挡位 4，bit9 写 1 请求重新捕获。
  0xA8：只读 0x54524B31，ASCII TRK1。
  0xAC：原子结果字：
        [31:16] 16 位结果序号（包含使能/复位失效通知）
        [15] 检测使能；[14] 有效；[13:12] SEARCH=0 / LOCK=1 / LOST=2
        [11:10] X 方向；[9:8] Y 方向：0 保持，1 左/上，2 右/下
        [7:6] X 等级；[5:4] Y 等级；[3:0] 保留为 0
  0xB0：[12:0] X 有符号偏差；[28:16] Y 有符号偏差，各为 13 位二补码。
        要读取误差快照，按 STATUS / ERRORS / STATUS 顺序读取，序号变化则重试。
        控制只用一个原子 STATUS 字，不存在 MCU 分次读取误差撕裂的问题。

FD / TCM 调试步骤
  1. 使用本次生成的 camera_red_tracking_20261016.bit 配置 FPGA。
  2. FD 选择本次 anlu_app ELF，沿用项目已有板载 JTAG/OpenOCD 的 RAM 下载流程。
     默认 launch 指向工程 build/anlu_app.elf；确认重建并下载 V2 ELF，而非仅继续运行旧 RAM 程序。
     若板上已有支持 TRK1 的 FPGA，V2 只需更新 MCU，FPGA 位流继续使用。
     不使用 anlu_app2 的 Flash 下载脚本，不更改 JTAG/PAD/复位向量设置。
  3. 启动后检查 g_track_capability == 0x54524B31，再进入显示模式第 4 项。
  4. 首先用较大的红色物品确认 LOCK 和框位置。需要先只看框时，GDB Console：
        set var g_track_config.enabled = 0
     首次低速测试可以设置：
        set var g_track_config.max_step_us = 2
        set var g_track_config.enabled = 1
  5. 分别将物品放在中心右侧、上侧，确认物品偏差逐渐变小。
     V2 默认 pan_sign=-1、tilt_sign=+1，依据用户反馈反转首版两轴自动方向。
     某轴反向时，先禁用跟随，再把该轴符号在 +1/-1 间反转后重新启用：
        set var g_track_config.pan_sign = -1
        set var g_track_config.tilt_sign = 1
     上面两条命令是 V2 默认值；只有实测仍反向时才再次改变对应符号。
     任一符号设 0 可以单独禁止该轴自动运动。max_step_us 超过 4 仍按 4 限制。
  6. 移走物品，应显示 LOST 并保持舵机位置；重新捕获后恢复。
     拖动时只接受手动控制；退出挡位 4 应保持当前位置。
  7. 可观察 g_track_control.sample / seen_ms / move_ms / reason：
     reason：0 OFF、1 WAIT、2 SEARCH、3 LOCKED、4 MANUAL、5 STALE。
     MCU 无串口也可以在 FD 中检查上述变量。精确板上版本须另行读回确认。
