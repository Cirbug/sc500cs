Gamma 滑动调节（GAM1，2026-10-22）
=====================================

目标：把图像设置页的 Gamma 从 OFF/ON 改成和曝光一样的滑条，同时保持
Sobel（边缘检测）自动使用当前 0.45 曲线，不受用户档位影响。

一、用户界面
------------
图像设置 -> 伽马：
  0    = OFF（旁路）
  1    = 0.30
  2    = 0.35
  3    = 0.40
  4    = 0.45（默认值；与旧 gamma 表逐点一致）
  5    = 0.50
  6    = 0.55
  7    = 0.60
  8    = 0.65

操作与曝光/亮度滑条一致：
  - 物理键：UP/DOWN 调一档，OK 进入/退出编辑；
  - 触摸：点左侧减、右侧加，或直接拖动滑条；
  - 菜单显示 OFF 或 0.30..0.65；
  - “恢复默认”回到 OFF（PICTURE_DEFAULT=0x108c）。
  - 档位循环：0 -> 1 -> ... -> 8 -> 0，反向同理。

Sobel（MODE 2 / EFFECT 5）：
  - 硬件强制使用档位 4（0.45），即旧版曲线；
  - 菜单显示 0.45，不显示滑条；
  - Sobel 期间伽马不可编辑；退出 Sobel 后恢复用户档位；
  - 用户原档位保存在 MenuState，不会被 Sobel 覆盖。

二、APB 寄存器
--------------
GAM1 使用 APB 0x6c（未改动 PIC1 0x70/0x74）：

  写 0x6c：低 4 位 = gamma_level，0..8，大于 8 钳到 8。
  读 0x6c：0x47414D30 | gamma_level，即 "GAM" + 低 4 位档位。
           旧 bit 读到 0，新 MCU 据此隐藏滑条并回退 OFF/ON。

PIC1 的 bit6 仍然是 gamma enable：
  - 新 MCU 写 GAM1 档位时，同时让 bit6 = (level != 0)；
  - 旧 MCU 只写 bit6 时，新 FPGA 默认使用 0.45；
  - 新 MCU 读不到 GAM1 时，退回旧 OFF/ON 行为。

GAM1 与 PIC1 一起通过 20-bit 的 picture_control_cdc 在原始帧边界提交：
  [19:16] = gamma_level，[15:0] = PIC1 picture word。
  这样档位和 bit6 不会在帧中间撕裂。

三、FPGA 实现
-------------
rgb96_gamma（user_source/hdl_source/isp/isp_top.v）：
  - 8 条固定曲线 + 旁路；
  - 每条曲线：x=0..15 逐点精确值，x=16..255 为 16 段线性插值；
  - 256 x 16-bit 系数 ROM，条目 = {base[7:0], slope[7:0]}；
  - 12 路并行读系数，每拍 4 个 RGB888 像素；
  - 四拍流水：输入寄存 -> 同步系数 ROM -> 插值/旁路寄存 -> 数字亮度 + 输出寄存；
  - 插值：y = base + ((slope * x[3:0]) >> 4)，饱和到 255；
  - 数字亮度仍在 gamma 之后，四档移位相加不变；
  - I_enable=0 时原样旁路，流水线延迟不变。

曲线精度：
  - 0.45 档与旧版 256 项表逐点一致；
  - 其余档对 255*(x/255)^gamma 的最大误差约 2 LSB；
  - 低端 0..15 逐点精确，避免暗部插值误差。

四、固件差异（重要）
--------------------
TCM 固件（FDwork/anlu_app）：
  - 原有 48 KiB TCM 在改动前只剩 16 字节连续空隙；
  - 加入滑条代码 + 约 424 字节 text 后，heap 与 stack 重叠，链接失败；
  - 因此 TCM 构建定义 GAMMA_SLIDER=0，保留旧 OFF/ON，不包含滑条；
  - 这样可以继续保留 1 KiB heap + 2 KiB stack，不牺牲内存安全。

XIP 固件（FDwork/anlu_app2）：
  - 定义 GAMMA_SLIDER=1，包含完整 8 档滑条；
  - 当前 XIP DLM 连续空隙约 3792 字节，仍保留 1 KiB heap + 2 KiB stack；
  - 新功能应使用 XIP 固件。

构建入口：
  ./FDwork/anlu_app/build.ps1  -FdRoot D:/FD/FD -BuildRoot <out>/firmware_tcm
  ./FDwork/anlu_app2/build.ps1 -FdRoot D:/FD/FD -BuildRoot <out>/firmware_xip

FD 默认输出同步（2026-10-22）：
  FDwork/anlu_app2/build/anlu_app2.elf/.bin/.map 已替换为本次 8 档 XIP 固件；
  使用 FDwork/anlu_app2/anlu_app_onecable.launch 时，PROGRAM_NAME 指向
  build/anlu_app2.elf，因此会加载新固件。
  FDwork/anlu_app/build/anlu_app.elf 仍是 TCM 构建，按设计没有滑条；
  不要把它当作 gamma 滑条的验收固件。

六、风险
--------
  - Gamma 在 DDR 之前，滑条会同时影响显示、识别/跟踪输入和 AE 测光；
  - 8-bit 表没有 dithering，暗部渐变可能出现 banding；
  - 0.45 档与旧表一致，但其他档仍是近似曲线（<=2 LSB）；
  - 新 bit 与旧 bit 的 GAM1 能力不同，必须配套使用；
  - TCM 不包含滑条，只有 XIP 有；不要把 TCM 当作该功能的验收固件。
